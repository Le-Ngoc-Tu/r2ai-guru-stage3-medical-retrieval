# R2AI Stage 3 reel - design

Concept: a retrieval system drawn as a precise instrument - hairline grids, dot matrices and odometers on a
deep ink-teal field, with one warm amber for "found it". The reel ends on the README's light paper palette so
the film and the repo banner read as one identity. League Gothic carries statements and numbers (condensed,
tall, supports Vietnamese diacritics); JetBrains Mono carries system labels (ASCII only); Noto Sans JP only for
the two hanzi. Teal = system, amber = result. No gradients on dark fields (banding), only radial glows.
