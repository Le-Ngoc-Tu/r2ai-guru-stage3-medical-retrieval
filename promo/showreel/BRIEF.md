## Intent

A 15-second motion-design showreel for the R2AI GURU Stage 3 project (multilingual medical retrieval),
used as a CV/portfolio piece and as the README video. "Go all out": dense, percussive, authored
entirely in HTML/GSAP. Every number on screen is a measured number from this project
(docs/NHAT-KY-DU-AN.md), nothing invented.

## Customizations

- Silent by decision of the author (an earlier synthesized sound design was removed before publishing).
- Second deliverable: a silent 6.4s looping README banner (1280x400) animating assets/banner.svg (see ../banner).

## Notes

- Autonomous run (user said "go all out", no questions). Scenes: query typing, scale odometers,
  pipeline, score climb, "3 vs 71" twist, outro lockup on the light README palette.
- Fonts: League Gothic (display, has Vietnamese glyphs), JetBrains Mono ASCII only (it lacks d-stroke and u-horn).
